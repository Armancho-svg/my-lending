# 🎨 Профессиональный Портфолио Сайт

Современный, адаптивный портфолио-сайт, созданный на чистом HTML5, CSS3 и JavaScript без использования фреймворков и библиотек.

## ✨ Особенности

### 📱 Адаптивность
- **1440px** - Full HD дизайн
- **1024px** - Tablet версия
- **768px** - iPad версия
- **375px** - Mobile версия
- **Дополнительная оптимизация** для устройств < 360px

### 🎯 Функциональность
- ✅ Фиксированное меню с плавным скроллом по якорям
- ✅ Бургер-меню для мобильной версии с анимацией
- ✅ Плавное появление блоков при скролле
- ✅ Кнопка "Вернуться в начало" страницы
- ✅ Контактная форма с валидацией
- ✅ Современные hover-эффекты на кнопки и карточки
- ✅ Плавная прокрутка страницы

### 🎨 Дизайн
- Минималистичный современный стиль (white/black + accent color)
- CSS переменные для удобной кастомизации цветов и шрифтов
- BEM-нейминг для всех классов
- Flexbox и CSS Grid для макета
- Профессиональный уровень UI/UX

### 📦 Структура Сайта
1. **Header** - Фиксированное меню с логотипом
2. **Hero Section** - Приветственная секция с CTA кнопками
3. **About** - Информация об авторе со статистикой
4. **Skills** - 6 карточек с основными навыками
5. **Portfolio** - 3 карточки проектов с описаниями
6. **Services** - 6 услуг в формате карточек
7. **Contact** - Форма контакта с информацией
8. **Footer** - Подвал сайта со ссылками

## 🎨 Кастомизация

### Изменить Цвета
Отредактируй CSS переменные в `styles.css` (строки 1-21):

```css
:root {
    --color-primary: #2563eb;        /* Основной цвет */
    --color-accent: #10b981;         /* Акцентный цвет */
    --color-text: #1f2937;           /* Цвет текста */
    /* ... остальные переменные */
}
```

### Изменить Шрифты
Обнови переменные шрифтов:

```css
--font-family: 'Твой шрифт', sans-serif;
```

### Добавить Свои Данные
1. **Имя и описание** - отредактируй текст в hero section
2. **Скиллы** - обнови .skill-card элементы
3. **Проекты** - измени .portfolio-card содержимое
4. **Контакты** - обнови email и телефон в contact section
5. **Социальные сети** - измени ссылки в footer

## 💡 Советы по Расширению

### Добавить Новую Секцию
1. Добавь элемент в HTML с `id="новая-секция"`
2. Добавь ссылку в навигацию
3. Стилизуй с использованием существующих переменных
4. Добавь анимацию с классом `data-animate="true"`

### Подключить Backend
```javascript
// В script.js измени contactForm submit handler:
fetch('/api/contact', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name, email, subject, message })
});
```

### Добавить Светлую/Тёмную Тему
Добавь в HTML:
```html
<button id="themeToggle">🌙</button>
```

И переключай классы через CSS:
```css
body.dark-theme {
    --color-bg: #1f2937;
    /* остальные цвета */
}
```
